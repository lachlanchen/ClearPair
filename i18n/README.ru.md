# ClearPair by LazyingArt

[![11 UI languages](https://img.shields.io/badge/UI-11_languages-456BA4?style=for-the-badge)](../docs/LOCALIZATION.md) [![GitHub Sponsors](https://img.shields.io/badge/Sponsor-lachlanchen-EA4AAA?style=for-the-badge&logo=githubsponsors&logoColor=white)](https://github.com/sponsors/lachlanchen)

*Тренируйте то, что путаете. Учитесь различать.*

Восемь курсов для легко смешиваемых звуков и букв на iOS, Android и PWA. ClearPair — рабочее название; L & N остаётся отдельным приложением.

![ClearPair](../docs/assets/eight-icons-v4.png)

[Обновление оценки только для H & F](../docs/HANDF-NATIVE-SCORING-20261003.md) распознаёт сохранённые записи английской и китайской речи нативно на iOS, с встроенным офлайн-резервом вместо зависимости только от декодера WebView. Идентификация слова остаётся отдельной от измеренных деталей звука; причины неудачной оценки сохраняются вместе с аудио в истории. Другие курсы и текущие официальные проверки не изменены. Проверка исходного кода не означает доступность в магазине или подтверждённую точность на голосах людей.

Все восемь отдельных приложений, включая [японское](../docs/JAPANESE-COURSE.md), доступны как [внутренние тестовые сборки 1.0.0 (9) со ссылками](../docs/BETA-1.0.0-9.md) в TestFlight и Google Play. Восемь официальных заявок iOS по-прежнему используют сборку 8 и ожидают проверки; автоматический выпуск после одобрения сохранён. Отправка Google в производство ещё не завершена. [Подписанные пакеты и состояния магазинов проверены](../store/artifacts/internal-beta-1.0.0-9.json). Это внутреннее тестовое обновление не означает одобрения или публичной доступности. Публичная PWA не изменена.

## Предварительная версия

Реализованы слуховые задания, воспроизведение/повтор пар, учебные схемы, интервальное повторение, волны, история и экспорт записей. Исходный код поддерживает все 11 языков профиля независимо от языка практики. Специальные фонетические заметки остаются на английском/китайском; непереведённые явно помечены как английские.

Иконки V4 задают палитру: светлый фон, плавный цвет, аккуратные карточки и стабильное положение управления записью/воспроизведением. Старые иконки сохранены. Необязательные анимации и игры из пяти вопросов дают локальные звёзды за слушание/память, а не непроверенные оценки произношения. См. [языковой охват](../docs/LOCALIZATION.md) и [заметки о кантонском](../docs/CANTONESE.md). [Бета 0.2.0 (2) семи приложений](../docs/BETA-0.2.0.md) включает V4, все 11 языков интерфейса и кантонское приложение.

**Сборка 9 улучшает автоматическую нативную оценку сходства.** Нажмите запись, произнесите слово и сделайте паузу либо нажмите остановку с оценкой. В тихих коротких словах сохраняются слабые начальные и конечные согласные; различающийся начальный звук, гласный или окончание получает больший вес, чем общие звуки. H & F показывает звук, гласный/слово и относительную длительность; остальные курсы показывают сходство слова, контраст и длительность речи. Элементы записи остаются над результатами. Это локальные индексы сходства с образцами, не калиброванные проценты правильного произношения. Нужен установленный офлайн-голос языка занятий; калиброванные оценки фонем и оценивание PWA остаются отключёнными. См. [описание алгоритма](../docs/SCORING-UPDATE-20261002.md). Capacitor объединяет React с нативной записью и речью Swift/Java; это не отдельные интерфейсы SwiftUI/Compose.

## Сборка и тестирование

Нужны Node 22+, npm, Android SDK/JDK 21 и Mac с Xcode для iOS. Сборки выполняются последовательно. Браузерные тесты проверяют поведение, а не фонетическую точность.

```sh
npm ci --legacy-peer-deps
npm run dev
npm test
npm run build
npm run test:e2e
npm run native:sync -- handf android
npm run native:sync -- handf ios
node tools/native-family.mjs --android-build
```

ID приложений: `handf`, `landr`, `english`, `chinese`, `korean`, `arabic`, `cantonese`, `japanese`; идентификаторы пакетов: `art.lazying.clearpair.<id>`. PWA собираются в `dist/site`. Отладочные APK не являются релизами Play. Доступность тестирования должна подтверждаться проверенным ответом магазина.

## Аудио и конфиденциальность

Записи микрофона остаются на устройстве; приложение их не загружает на сервер. Экспорт открывает нативное меню обмена или скачивание в браузере. Получателя выбираете вы. Сохранение может не сработать; очистка данных или удаление приложения могут стереть записи. Экспортируйте важные файлы.

Временные синтетические исследовательские записи не включены: права на распространение и проверка произношения человеком не подтверждены. Тестовые сборки используют установленные голоса устройства. Качество, языки и работа без сети различаются; поставщики голосов могут использовать сетевые сервисы.
